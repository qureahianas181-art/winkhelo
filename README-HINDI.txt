WINKHELO — FREE WEBSITE (Hindi Guide)

1) ZIP ko extract karein.
2) GitHub repository "winkhelo" kholen.
3) Add file > Upload files par tap karein.
4) Extracted folder ke ANDAR ki files (index.html, manifest.webmanifest, sw.js, README-HINDI.txt) upload karein. Folder ko nested upload na karein.
5) Commit changes karein.
6) Repository Settings > Pages > Build and deployment me "Deploy from a branch" select karein.
7) Branch: main, Folder: /(root), phir Save.
8) Kuch minute baad URL hoga: https://qureahianas181-art.github.io/winkhelo/

NOTE: Ye browser-based free-play prototype hai. XP local browser me store hota hai. Isme account/login, cloud save, online leaderboard, admin panel, payment ya cash prizes nahi hain. XP ka cash value nahi hai.
Google indexing guaranteed nahi hoti. Site live hone ke baad Google Search Console me URL inspect karke indexing request kar sakte hain.
